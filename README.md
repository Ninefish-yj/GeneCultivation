# 基因修炼 (GeneCultivation)

WorldBox 0.51 + NeoModLoader 原创现代异能模组。**13阶阶位 + 56基因序列 + 398异能 + 9档品质 + 神名系统 + 圣所跨存档 + 维度空间 + 大场面战斗体系**，异能能量/失控指数/基因图谱驱动沙盒自主演化，至高者可跨存档互通。

- 仓库：https://github.com/Ninefish-yj/GeneCultivation
- 当前版本：**v0.21.31**

---

## 一、特性总览（v0.21.31）

### 阶位与修炼
- **13阶阶位**：F级 → E级 → D级 → C级 → B级 → A级 → S级 → 称号级 → 天灾级 → 使徒级 → 登神级 → 真神级 → 超神级
- **基因觉醒**：凡人觉醒为异能者（1阶）即获"觉醒之心"；基因图谱 56 基因真实生效（攻击/防御/速度/生命/能量/修炼/失控/冷却/减伤/暴击/吸血/治疗/特殊能力）
- **表达层级**：沉默0% / 低25% / 中50% / 高100% / 过150% / 突变200%——表达层级决定基因效果强度
- **境界压制**：高阶对低阶即时真伤 + 伤害减免；**能量抵伤**：受伤先耗异能能量
- **纪元**：登神切换超神纪元（协调效应基因属性翻倍、植被生长加成、神圣粒子）

### 异能系统（v0.17+ 重构，v0.20 全量扩编）
- **398 异能全量库**：14 大类（元素/强化/精神/时空/生命/死亡/暗影/光明/机械/自然/声音/混沌/血神/兽化），每异能有名有表现，同组合标签零重复
- **50 标签引擎**：异能按标签组合驱动真实战斗机制（灼烧/冻结/暴击/吸血/诅咒/恐惧/连锁/斩杀/护盾/闪避/传送/再生/光环/标记/吸能/领域……）
- **9 档品质**：F级 → E级 → D级 → C级 → B级 → A级 → S级 → SS级 → SSS级（字母等级制，网文异能感）；品质是异能品阶，不改变异能本体
- **原版基因桥接**：原版基因按亲和映射异能标签（觉醒定相/天生亲和）

### 神名系统（v0.18.4x 定型）
- **神名与异能一一对应**：196+ 异能原型各有专属神名（意象随异能本体，品质不参与选词）
- **20 意象域 × 神位制**：东西方双风格成对授予（东方道教尊号 / 西方领域神称号），同语言双显
- **神名独属单位**：跨存档唯一注册表，同异能第二个登神者取世系后缀（·贰 / ·III）
- 登神文案/加冕记录/维度 tab 神名展示全链路一致

### 圣所 · 跨存档移动仓（v0.18.52）
- 圣所放置 = 真·复刻：整档快照（基因序列 + 特质 + 亚种/氏族/文化/语言），放置后移出原世界
- 从存档 A 移动到存档 B，原存档不再保留该单位；跨存档神名唯一性保证

### 维度空间（v0.13 世界级改造）
- 真·独立地图：世界切换、空间居民化身按原种族重建
- 能量经济闭环（产出/维持/消耗/衰退）、随机事件（潮汐/裂缝/入侵）、主宰权限（封禁/倍率调控）
- 真隐藏：无敌+不可见+AI 暂停

## 二、安装

1. 下载最新 `GeneCultivation_vX.Y.Z.zip`
2. 解压到 WorldBox 模组目录：`<游戏目录>/Mods/`（zip 顶层文件夹 `GeneCultivation` 与 mod.json GUID 一致）
3. 从 Steam 启动 WorldBox 0.51（0.51.2+），NeoModLoader 自动加载
4. 手机端更新需**先删除旧模组文件夹**再解压新包
